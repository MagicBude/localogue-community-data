# 共享边界与许可

## 本仓库共享什么

优先共享结构化事实：

- 人物公开职业姓名及名称历史
- 公开职业状态与职业事件
- 公开生日/出生地/身高等职业资料（仅在确有公开来源时）
- 作品番号、标题、日期、时长
- Maker / Label / Series / Genre 关系

## 当前不共享什么

- 用户本地 MediaFile 路径、文件 Hash、观看记录、评分
- 用户个人 Tag、备注和 Presentation Preference
- 私人联系方式、私人地址、未公开身份信息
- 未获再分发许可的头像、封面、剧照等图片
- 从第三方站点原样复制的长篇简介、评论、文章或付费内容
